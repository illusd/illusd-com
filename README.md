首頁下方是精選文章

文章只有預先註冊的兩人可以發布

首頁右下角有加號按鈕（創作者的）

可以新增文章（全屏覆蓋不要彈窗）

可以放文章大圖/標題/集數

集數是依照標題來例如標題是

#1 (平台選擇)-VIBE人人都可實現

#1是集數

()裡面的是該集標題

-後面的是話題標題

顯示時要自動去掉例如：

原：#1 (平台選擇)-VIBE人人都可實現

去：Ep.1  平台選擇   自「VIBE人人都可實現」

建立文章時可以直接選擇話題標題也可以使用格式

所有人都有右上角的三條線可以選擇頁面

新增頁面/topic/all

是可以看所有文章

預設值顯示標題與照片，需要點進去才能看到完整文章

並且可以選各個話題與各個話題的集數並給予

新增頁面/sigh-up

這個是登入註冊頁面

可以用Google帳號登入(之後接你先用lovable的）

註冊或登入完成就可以評論與按讚了（在各個文章裡面）

註冊要加上cloudflare的email
